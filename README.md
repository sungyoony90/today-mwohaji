# 오늘 뭐하지?

오늘 할 활동을 고르고, 가볼 만한 장소를 찾고, 다녀온 순간을 기록하는 토스 미니앱입니다.

## 과제 제출용 공개 소스

2026-10-06 최신 개발 폴더를 기준으로 만든 공개용 스냅샷입니다. 오래된 작업 브랜치를 일괄 병합하지 않았으며, 운영 저장소의 과거 Git 이력은 포함하지 않았습니다.

- 산책·러닝·전시·독서·카페·액티비티 중심 장소 탐색
- 지역·위치 기반 장소 목록과 지도 서비스 선택
- 서울시 지원 권역 혼잡도 및 별도로 구분한 규칙 기반 예상 혼잡도
- 방문 사진 기록, 장소/순간 저장, 모아 수집
- 토스 SDK 뒤로가기, 사용자 식별 연동, 선택형 GA 분석
- Origin 변경에 대응하는 제한적 로컬 기록 이전

## 실행

Node.js 22 이상을 권장합니다.

```sh
npm ci
node server.mjs
```

서버에 표시되는 로컬 주소를 열어 확인합니다. API 키가 없으면 외부 API 기능은 제한되거나 대체 응답을 사용합니다.

```sh
npm test
npm run build:web
```

## 운영 서비스와의 차이

개인 사진은 캐릭터 이미지로 대체했습니다. 운영 Supabase 주소·공개 클라이언트 키와 GA 측정 ID는 예시 값으로 바꿨습니다. 따라서 공개본은 운영 데이터에 연결되지 않으며, 사진 저장·사용자 식별·GA 전송 등을 실제로 사용하려면 본인 프로젝트 설정이 필요합니다. 정식 배포하려면 본인 앱 식별자와 서버 설정도 구성해야 합니다.

서버 예제와 데이터 정책은 `supabase/`, 프런트 연결 설정은 `runtime-entry.js`, 분석 설정은 `ga-analytics.js`에 있습니다. 비밀 키는 서버 환경에만 등록해야 합니다.

## 공개 제외 항목

`.env` 전체, 앱 번들, 빌드 결과, 인증서·개인 키, 사용자 사진·데이터, 개인 주소가 포함된 작업 문서, 라이선스 확인이 필요한 로컬 폰트 및 과거 Git 이력은 제외했습니다. 장소 검수 테스트에 필요한 공개 장소 목록 JSON만 포함합니다.

코드 자동 테스트는 실기기 검수나 실제 서비스 지표 검증을 대신하지 않습니다. 배포 앱의 성과와 분석 수신 여부는 별도 검증 대상입니다.
